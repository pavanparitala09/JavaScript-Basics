# Week 1: JavaScript Basics & Fundamentals

This week covers core JavaScript programming concepts. It establishes the foundations of language syntax, variable operations, functions, control flow (conditional statements), array methods, and object manipulations.

## Directory Contents

* **[Array_Operations](./Array_Operations/)**: Practical exercises utilizing ES6 array methods such as `filter()`, `map()`, `reduce()`, `find()`, and `findIndex()`.
* **[If_Else-Conditions_Based_task](./If_Else-Conditions_Based_task/)**: Real-world logic modeling using conditional control flow structures (`if`, `else if`, `else`).
* **[Object_Array](./Object_Array/)**: Complex data structure manipulation involving arrays of objects (e.g., student lists, cart items, etc.).
* **[Object_Operations](./Object_Operations/)**: Object creation, property access, key-value manipulation, and checking states.
* **[Simple_function_for_TotalSum.js](./Simple_function_for_TotalSum.js)**: A basic JavaScript function script simulating a cart checkout total calculation applying discount and GST.

## Key Learning Objectives
1.  Understand basic scoping, variables, and function declarations.
2.  Manipulate lists using advanced declarative array operations instead of standard imperative loops.
3.  Design and modify nested JS object models.
4.  Execute conditional statements to direct program paths based on criteria.
