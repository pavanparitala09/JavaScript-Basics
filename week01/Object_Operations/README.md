# JavaScript Object Operations Assignments

This directory contains assignments that focus on working with single JavaScript objects. Exercises cover basic property CRUD (create, read, update, delete) operations, object structure manipulation, and looping properties using iteration techniques.

## Files & Scenarios

### [Assignment01.js](./Assignment01.js): User Profile Manager
* **Scenario**: Managing a logged-in user's profile metadata in a web app.
* **Tasks**: Creating property paths, updating role/email keys, and accessing nested attributes dynamically.

### [Assignment02.js](./Assignment02.js): Exam Result Summary
* **Scenario**: Managing subject-wise marks mapping.
* **Tasks**: Iterating through object keys/values (using `Object.keys()` or `for...in`), calculating sum totals, and determining average pass metrics.

### [Assignment03.js](./Assignment03.js): Application Settings Controller
* **Scenario**: Managing user preference control states (e.g., theme, notification switches).
* **Tasks**: Reading, toggling, and overriding boolean flags dynamically.

## ️ Usage
To run the object manipulation scripts, use Node.js:
```bash
node Assignment01.js
node Assignment02.js
node Assignment03.js
```
