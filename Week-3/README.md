# Week 3: Express.js Backend Development

This week focuses on creating backend services using Node.js and **Express.js**. It covers routing, request parsing, database integration using **Mongoose / MongoDB**, and authentication middleware.

## Directory Contents

* **[Backend-Demo](./Backend-Demo/)**: An introductory in-memory Express.js server containing modular user and product routers (`express.Router()`).
* **[Backend-Demo2](./Backend-Demo2/)**: An advanced Express server connecting to a local MongoDB database (`anuragdb`) via Mongoose. Features user authentication, token verification middlewares, and error-handling middleware patterns.

## Key Learning Objectives
1.  Initialize and run Express servers.
2.  Use body parsers (`express.json()`) to read request payload structures.
3.  Design and mount modular routes (`express.Router`).
4.  Configure local MongoDB connections and define schema layouts using Mongoose.
5.  Implement cookies (`cookie-parser`) and token-based validation protocols.
