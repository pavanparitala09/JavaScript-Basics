# Week 9: React Blog Frontends (State & UI)

This week focuses on designing dynamic UI layouts and handling state integration using **Zustand** stores for a blogging system.

## Directory Contents

* **[blog-app-frontend](./blog-app-frontend/)**: A responsive React blogging frontend workspace (inside `anurag-blogapp-frontend-b1-master`) demonstrating page grid layouts, responsive cards, toast feedback alerts, and dynamically loaded articles.
* **[blog-frontend](./blog-frontend/)**: A React web application utilizing **Zustand** (`src/store/authStore.js`) for authentication state management, routes guarding, and admin/author/user dashboards.

## Key Learning Objectives
1.  Manage client state stores using Zustand.
2.  Deploy toast notifications (`react-hot-toast`) for UX cues.
3.  Design multi-column responsive grid card profiles for authors and readers.
4.  Handle dynamic routing parameter filters based on article IDs.
