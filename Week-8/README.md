# Week 8: React Global State, Routing & API Fetching

This week covers advanced state sharing architectures, routing layout engines, remote third-party API integration, and full-stack project assemblies.

## Directory Contents

* **[context-demo](./context-demo/)**: A React web app using React Context API (`createContext`, `useContext`) to share counter states globally without prop drilling.
* **[Country_Search](./Country_Search/)**: A real-time client search catalog that calls the REST Countries API to query and render details about different countries.
* **[react-product-app-demo](./react-product-app-demo/)**: A component-based shopping catalog app illustrating interactive filter panels.
* **[react-routing-demo](./react-routing-demo/)**: An application demonstrating client-side routing using **React Router DOM v6** (with layout wrappers, routes parameters, navigation links, and redirects).
* **[user-management-app](./user-management-app/)**: A full-stack (MERN) application with a split Express + Mongoose server (`backend`) and a React client interface (`frontend`).

## Key Learning Objectives
1.  Manage state sharing using **React Context** and **Zustand** stores.
2.  Consume RESTful web services via HTTP libraries (`fetch`/`axios`) and handle promise hooks.
3.  Deploy client-side routers to handle multi-view structures.
4.  Connect separate React frontends to Express API backends.
