# User Management Frontend (React + Vite)

The client user interface for querying and updating user accounts.

## 📂 Architecture

*   **[src/components/](./src/components/)**: Contains registration forms, lists, search widgets, and card components.
*   **[src/App.jsx](./src/App.jsx)**: Orchestrates page state and makes HTTP calls to the backend APIs.

## 🔌 API Connection
Communicates with the backend server via `fetch` requests (typically targeting `http://localhost:5000/api/users`).

## 🛠️ Commands
*   Install: `npm install`
*   Run: `npm run dev`
