# Product Inventory Dashboard (React)

A React frontend dashboard managing catalogs, search filters, and lists of products.

## 📂 Architecture

*   **[src/components/](./src/components/)**: Components representing pricing panels, descriptions, grids, item pages, search text queries, and catalog category filters.
*   **[src/App.jsx](./src/App.jsx)**: Global container managing active filters and data flows.

## 🛠️ Usage
1.  Install packages: `npm install`
2.  Launch: `npm run dev`
