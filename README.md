# MERN Stack & JavaScript Training Repository

Welcome to the comprehensive training repository for JavaScript and the MERN (MongoDB, Express.js, React, Node.js) Stack. This repository traces the learning path from core JavaScript fundamentals up to full-stack production-ready applications.

## 📌 Repository Overview

This repository is organized week-by-week, detailing assignments, conceptual demos, CLI tools, frontend designs (HTML/CSS/Tailwind), and backend service implementations.

---

## 📅 Weekly Curriculum & Folder Structure

### 📁 Basic JavaScript & CLI Applications
*   **[week01](./week01/)**: Core JavaScript foundations. Covers array operations, if-else conditional tasks, object structures, arrays of objects, and simple functions.
*   **[week02](./week02/)**: Memory management and command-line interfaces. Includes shallow vs. deep copies, Date object manipulations, and a custom CLI-based **Task Validator** tool.

### 📁 Express.js & Backend Development
*   **[Week-3](./Week-3/)**: Introduction to HTTP servers and Express.js. Contains simple APIs (`Backend-Demo` user/product routers) and database/auth middleware integrations (`Backend-Demo2` with JWT token verification and MongoDB models).
*   **[Week-4&5](./Week-4&5/)**: Building robust architectures. Includes a backend for an E-commerce system, a complete Blog App Backend using Cloudinary and Multer for file uploads, and basic HTML structure/tables frontend assignments.

### 📁 Advanced Styling & HTML/CSS Projects
*   **[Week-6](./Week-6/)**: Layouts and advanced CSS. Consists of multiple responsive HTML/CSS designs (Projects 1 to 8) and a dashboard styled using **Tailwind CSS** (Project 9).

### 📁 React Fundamentals & DOM Manipulation
*   **[Week-7](./Week-7/)**: Interactivity and introduction to React. Covers JavaScript DOM Manipulation (`JS-DOM-DEMO`) and basic React applications demonstrating task lists, forms, and component states.

### 📁 React State Management & Routing
*   **[Week-8](./Week-8/)**: Intermediate React patterns. Covers the React Context API, API integration (`Country_Search`), React Router DOM (`react-routing-demo`), and a connected User Management full-stack application.

### 📁 Full-Stack MERN Projects
*   **[Week-9](./Week-9/)**: Advanced full-stack implementations. Contains a full Blog App Frontend using React and a state-managed blogging dashboard using **Zustand** (`blog-frontend`).
*   **[week-10](./week-10/)**: Advanced topics and placeholders.
*   **[blog-app](./blog-app/)**: A modular Express.js backend project featuring models for users and articles, services, and middlewares (like JWT auth verification).

---

## 🛠️ How to run the projects

1.  **Backend Services**:
    *   Navigate to the respective backend directory (e.g., `cd blog-app` or `cd Week-3/Backend-Demo`).
    *   Install dependencies: `npm install`
    *   Configure environment variables: Create a `.env` file containing port numbers, DB URLs, etc.
    *   Start the server: `npm start` or `npm run dev` (if using nodemon).

2.  **Frontend Apps**:
    *   Navigate to the frontend directory (e.g., `cd Week-9/blog-frontend`).
    *   Install dependencies: `npm install`
    *   Run development server: `npm run dev`
