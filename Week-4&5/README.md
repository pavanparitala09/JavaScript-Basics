# Weeks 4 & 5: Advanced Backends & Frontend Foundations

This module contains two separate core learning paths:
1.  **Production-ready Express Architectures** (with DB connectivity, authentication, file storage via Cloudinary, and file parsers via Multer).
2.  **Frontend HTML & CSS Foundations** (working with page structures, nested lists, table styling, forms, and custom stylesheet layouts).

## 📂 Directory Contents

### 🖥️ Backend Applications
*   **[BLOG-APP-BACKEND](./BLOG-APP-BACKEND/)**: Full-featured blog content management engine featuring Cloudinary image uploads, Multer parser configurations, user dashboards, and role authorization middlewares.
*   **[E-commers-app-backend](./E-commers-app-backend/)**: Core server api containing models and handlers for an e-commerce platform.

### 🎨 Frontend Labs
*   **[Frontend](./Frontend/)**: Main HTML/CSS practice labs covering nested list hierarchies, city portal layout, forms, table structures, and a portfolio webpage.

## 🚀 Key Learning Objectives
1.  Manage multipart/form-data payloads (specifically image files) using Multer and stream them to remote media hosting platforms (Cloudinary).
2.  Design authorization guards (e.g., separating user, author, and admin accesses).
3.  Write semantic, modern HTML layouts, forms, and nested structures.
