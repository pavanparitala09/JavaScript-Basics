# City Information Portal (Multi-page Navigation)

An exercise in building multi-page HTML architectures and linking separate documents together using relative anchor tags.

## Files

* **[Cities.html](./Cities.html)**: The homepage portal which displays a directory of main Indian cities.
* **[bengulore.html](./bengulore.html)**: Information page about Bangalore.
* **[chennai.html](./chennai.html)**: Information page about Chennai.
* **[hyd.html](./hyd.html)**: Information page about Hyderabad.

## ️ Concepts Practiced
* Relative paths and anchoring (`<a href="./path.html">`).
* Linking text content and images correctly across separate files.
