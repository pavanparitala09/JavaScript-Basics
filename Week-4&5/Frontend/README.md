# HTML & CSS Foundation Labs

This directory contains introductory exercises to build layouts using HTML5 elements, semantic structure markup, tables, forms, and custom styles.

## 📂 Labs Outline

### 📁 Lab Subdirectories
*   **[Assignment-1](./Assignment-1/)**: Basic structural exercises implementing nested lists and standard web templates.
*   **[cities](./cities/)**: Multi-page city information guide connecting pages through navigation links.
*   **[project-1](./project-1/)**: A structured website styled with custom CSS.

### 📄 Individual HTML Exercises
*   **`basic.html`**: Introduction to headings, paragraphs, standard formatting, and paragraph groupings.
*   **`BlackGooseBistro.html`**: Building restaurant menu grids and formatting descriptive text.
*   **`forms.html`**: Form controllers including text inputs, radio selections, dropdown menus, and submissions.
*   **`NicksBeef.html`**: Menu content structured with text styles.
*   **`pochiCat.html`**: Responsive image display and simple content blocks.
*   **`tables.html`**: Data grid structuring using `<table>`, `<thead>`, `<tbody>`, `<tr>`, and `<td>` elements.

## 🚀 Usage
Open any `.html` file directly in a web browser (e.g., Google Chrome, Microsoft Edge) to view the rendered layouts.
