# Project 9: Tailwind CSS Layout

A modern dashboard or catalog interface styled entirely with utility classes from **Tailwind CSS v4**.

## Files

* **[index.html](./index.html)**: Layout using Tailwind utility classes for colors, layout, fonts, and responsiveness.
* **[style.css](./style.css)**: Source stylesheet containing the Tailwind imports.
* **[output.css](./output.css)**: Compiled distribution CSS containing parsed styles.
* **[package.json](./package.json)**: Node configurations and Tailwind dependencies.

## ️ Development Setup
1.  Navigate here: `cd project-9`
2.  Install packages: `npm install`
3.  Run compilation scripts to build CSS if necessary.
