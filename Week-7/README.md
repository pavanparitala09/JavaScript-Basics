# Week 7: JavaScript DOM & Introduction to React

This week represents the transition from static content and vanilla JavaScript scripting to dynamic browser interfaces and **React.js** single-page applications.

## Directory Contents

* **[JS-DOM-DEMO](./JS-DOM-DEMO/)**: A hands-on vanilla JS project utilizing the DOM API to capture events, select elements (`querySelector`), edit style behaviors, and append HTML elements.
* **[react-demo-1](./react-demo-1/)**: A Vite-powered React project demonstrating initial React concepts (functional components, props, hooks, single-state vs form-state management, and task list components).
* **[product-page](./product-page/)**: A catalog browser project implementing list mapping, grid layouts, and product card views.
* **[product-management-app](./product-management-app/)**: A React application focusing on component state management to add, update, and manage product inventory listings.

## Key Learning Objectives
1.  Query and manipulate DOM nodes dynamically using Vanilla JavaScript.
2.  Understand declarative programming and virtual DOM concepts under React.
3.  Manage state boundaries using the `useState` React hook.
4.  Implement form collections, component nesting, and props.
