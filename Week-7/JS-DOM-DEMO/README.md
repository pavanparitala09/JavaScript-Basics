# Vanilla JS DOM Manipulation Demo

A lightweight demonstration of Document Object Model (DOM) APIs in action, showing how browsers render elements and run scripting logic.

## Files & Structure

* **[index.html](./index.html)**: Main HTML structure with inputs, action triggers, and empty display lists.
* **[index.js](./index.js)**: Scripting module handling click capture events, target node selections, form values reading, and creating list elements dynamically.
* **[styles.css](./styles.css)**: Stylesheet outlining button states, text fonts, margins, and card borders.

## ️ Concepts Practiced
* Event listening: `element.addEventListener('click', callback)`.
* Node querying: `document.getElementById()`, `document.querySelector()`.
* DOM Updates: `document.createElement()`, `element.appendChild()`, `element.textContent`.
