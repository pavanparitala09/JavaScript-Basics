# Product Page Catalog (React + Vite)

A React single-page app (SPA) that displays course catalogs and items.

## Project Architecture

* **[src/components/](./src/components/)**:
    * `Products.jsx`: Contains course card collections.
    * `Product.jsx` / `Course.jsx`: Card grids representing information panels.
    * `Dashboard.jsx`: Nav and metric summary components.
* **[src/App.jsx](./src/App.jsx)**: Connects headers and catalog lists together.

## ️ Usage
1.  Install packages: `npm install`
2.  Launch application: `npm run dev`
