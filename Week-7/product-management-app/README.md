# Product Management App

A React web application focusing on CRUD operations (Create, Read, Update, Delete) to manage catalog products.

## 📂 Project Structure

*   **[package-lock.json](./package-lock.json)**: Dependency locks.
*   **[Frontend/](./Frontend/)**: Main React Vite application.
    *   `src/components/`: Subcomponents managing addition forms, listings, product cards, filters, and dashboard headers.
    *   `src/App.jsx`: Root UI mounting application state.
    *   `README.md`: Frontend build and execution details.

## 🛠️ Usage
1.  Navigate to the client app: `cd Frontend`
2.  Install packages: `npm install`
3.  Launch local server: `npm run dev`
