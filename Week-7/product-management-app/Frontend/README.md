# Product Management Frontend (React + Vite)

This is the user interface module of the Product Management Application.

## Architecture

* **[src/components/](./src/components/)**: Contains UI sections (Forms, Product lists, Filter search boxes).
* **[src/App.jsx](./src/App.jsx)**: Main orchestrator maintaining the state array of products.
* **[src/main.jsx](./src/main.jsx)**: Application mounting entrypoint.

## ️ Commands
* Install: `npm install`
* Development Server: `npm run dev`
* Build Application: `npm run build`
